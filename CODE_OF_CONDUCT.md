# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want this to be a friendly place for everyone, whatever their experience level, background or identity. Beginners are welcome; so are questions.

## Expected behaviour

- Be kind and patient. Assume good intent.
- Disagree with ideas, not people. The clipping debate in Discussions is meant to be a real debate: argue the point, don't attack the person.
- Give and accept constructive feedback.

## Not acceptable

- Harassment, insults, slurs, or personal attacks.
- Posting someone's private information.
- Sharing pirated content, real stream footage you don't have rights to, or anyone's credentials.

## Enforcement

The maintainer (@LucianCeusanRo) may remove comments, issues or discussions that break these rules and may block repeat offenders. Report problems by opening a private security advisory (Security tab → Report a vulnerability) or by contacting the maintainer through their GitHub profile.
